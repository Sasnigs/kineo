# Kineo

Kineo is an iPhone movement-planning app for adults with recurring neck or back discomfort. A short check-in selects a bounded, explainable routine from bundled content. Kineo does not diagnose or treat a medical condition.

The app is implemented with Expo SDK 57, React Native, and strict TypeScript. It targets iOS 17 or later and works locally without an account or network connection.

## Run locally

Requirements: Node 24.20.x, npm 11.19.x, Xcode, and an installed iPhone simulator.

```sh
cd apps/mobile
nvm use
npm ci
npm run ios
```

## Verify

```sh
cd apps/mobile
npm run typecheck
npm run lint
npm run test:ci
npm run dependencies:check
npm run audit
```

The native iOS project is generated by Expo and is not versioned. One small local Expo module uses Swift to enforce iOS file-protection and backup-exclusion attributes; product behavior remains in TypeScript.

The top-level Swift/Xcode app is retained temporarily for the final migration qualification. New product work belongs in `apps/mobile`.

Do not add networking, analytics, HealthKit, cloud storage, background modes, or new entitlements without an approved design change.
